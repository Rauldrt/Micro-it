Política de Privacidad — Whataudio

Última actualización: 19 de noviembre de 2026 Responsable: Whataudio / Micro-IT Studio

1. Resumen

Whataudio es una extensión para Google Chrome (y aplicación complementaria) que transcribe y resume notas de voz de WhatsApp Web utilizando motores de Inteligencia Artificial elegidos directamente por el usuario.

2. Datos que procesa la extensión

  • Audios de WhatsApp Web: únicamente se procesa el audio específico cuando el usuario hace clic en "Transcribir con Whataudio" sobre un mensaje de voz. La extensión no lee, indexa ni recopila otros mensajes, chats, contactos ni archivos de tu cuenta de WhatsApp.
  • Claves de API (opcional): si el usuario elige un motor en la nube (Groq, Google Gemini u OpenAI), su clave de API se almacena localmente en el almacenamiento del navegador (chrome.storage.sync) y se envía exclusivamente al proveedor seleccionado.
  • Historial de transcripciones: las transcripciones, resúmenes y tareas generadas se guardan únicamente en el almacenamiento local del navegador (chrome.storage.local) del usuario y pueden eliminarse en cualquier momento desde la pestaña Historial.

3. Modo Local Offline (100% en el dispositivo)

Cuando está activo el motor Local Offline (Whisper):

  • Los audios se decodifican y transcriben íntegramente dentro del navegador del usuario mediante WebAssembly (ONNX Runtime).
  • Ningún dato de audio ni texto sale de la computadora del usuario.
  • Solo se descargan los pesos públicos del modelo Whisper desde Hugging Face (huggingface.co) la primera vez que se utiliza, quedando cacheados localmente en el navegador.

4. Motores en la nube (opcionales)

Si el usuario configura su propia API Key de Groq, Google Gemini u OpenAI, el audio seleccionado se envía directamente mediante HTTPS desde el navegador del usuario a la API oficial del proveedor elegido, sujeto a las políticas de privacidad de dicho proveedor. Whataudio no opera servidores intermedios que almacenen, registren o revendan esos audios.

5. Compartición y venta de datos

Whataudio no vende, alquila ni transfiere datos de usuarios a terceros, ni utiliza los datos recopilados para publicidad, perfilado o fines ajenos a la funcionalidad principal de transcripción solicitada por el usuario.

6. Contacto
